# Project Rules

- Этот проект написан строго на React, TypeScript и Vite.
- Всегда создавай функциональные компоненты.
- Используй стрелочные функции (`const Component = () => ...`).
- Типизируй пропсы через `interface`.
- Пиши стили с помощью CSS-модулей или Tailwind CSS.
- **Никогда** не запускай браузерные тесты (`browser_subagent`) автоматически. Запуск браузерных тестов разрешен только по явному запросу пользователя.
